Network Security Audit

Overview

A beginner cybersecurity project investigating local Windows network configuration, listening ports, and firewall status.

Objectives

* Understand basic networking concepts.
* Use built-in Windows tools to inspect network information.
* Identify potential security risks without assuming every open port is vulnerable.
* Recommend defensive security practices.

Tools

* Windows Command Prompt
* ipconfig
* netstat
* Windows Security

Skills Demonstrated

* Network fundamentals
* Basic security auditing
* Command-line investigation
* Risk analysis
* Technical documentation

Scope and Ethics

Testing was limited to my own computer. No third-party systems were scanned, and no security settings were changed.

See network-audit.md for the observations, risk assessment, recommendations, and limitations.
